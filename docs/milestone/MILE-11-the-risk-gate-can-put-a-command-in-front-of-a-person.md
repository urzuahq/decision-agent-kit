# 11 — The risk gate can put a command in front of a person

## Outcome

In `on` mode, a command judged risky prompts the person. A command the harness would have asked about is still asked about.

## Done means

- A test shows the gate cannot turn a prompt into an approval (ADR-4). Evidence: the test.
- An ADR decides the default mode from the shadow record. Evidence: the ADR.
